# Meebit VRM 腕ボーン規約（normalized）

PFP Studio / 射的 / 歩行などで使う**落とし所**。Meebit のボクセル腕は「手のひらの向き」が崩れると一気に安っぽく見える。

正本: `src/photoStudio/poses.ts`（スタジオ）、`src/avatar/VRMLocomotion.ts`（attention / 射的 / 歩行）

## いちばん大事なコツ

**手をひねらない。**  
手のひらを表に向けたり後ろに向けたりする回転を入れると、肩・袖が壊れて見える。

腕を高く上げたいときも、**腕を捻らず・前後に振らず、下ろした向きのまま `z` だけで上げる。**

## 軸の意味（UpperArm）

| 軸 | 役割 | スタジオでの使い方 |
|----|------|-------------------|
| **z** | 上げ下ろし（体側 ↔ 横水平） | attention: 左 `+1.56` / 右 `−1.56`。**同じ符号のまま** `|z|` を減らすほど上がる（→0 でほぼ T）。**符号を反転すると掌が表を向いて壊れる** |
| **x** | 前後スイング | **スタジオでは基本 0。** 触ると掌の向きが変わる。射的の銃構えだけ例外（`x≈π/2` + attention `z`） |
| **y** | 捻り | **禁止** |

## LowerArm / Hand / Shoulder

- LowerArm: **x のみ**肘曲げ。`y/z = 0`
- Hand: 毎フレーム `{0,0,0}`（掌の残留捻り防止）
- Shoulder: 毎フレーム `{0,0,0}`

## 安全なパターン

| 意図 | やり方 |
|------|--------|
| 下ろす | `upper x=0,y=0`, `z=attention` |
| 高く上げる（Cheer / Wave） | `x=0,y=0` のまま `|z|` だけ減らす |
| 肘を曲げる（腰に手・力こぶ・胸前） | 上腕は下ろしたまま（attention `z`）+ `lowerArm.x` 大 |
| 着席 | 脚だけ。腕は rest（`applyVRMSitPose`） |

## やってはいけないこと

1. 上げるために **UpperArm.x** を入れる（ゾンビ前出し＆掌が回る）
2. **UpperArm.y** で掌を回す
3. 肘の `y/z` を触る
4. 一部軸だけ書いて前ポーズの捻りを残す

## 限界とポーズ選定

- 完全な腕組み・腰に手・力こぶは、肘曲げ近似でも掌／肩が崩れる → **採用しない**
- PFP Studio では代わりに次を使う: お辞儀 / 両手開き / 振り向き / ヒーロー立ち（体幹・脚・z 上げ中心）
- 射的の前方銃構えは意図的に `x` を使う例外（掌より銃の向き優先）
