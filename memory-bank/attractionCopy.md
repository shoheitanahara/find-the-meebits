# アトラクション看板・スタートカードのコピー

入口は遊園地のアトラクションだ。説明書ではなく、**ディズニーの入口看板**のように書く。

最終更新: 2026-08-12

関連実装:

| 用途 | パス |
|------|------|
| 入口看板 | `src/top/topConfig.ts` の `storyTitle` / `description` |
| 看板レイアウト | `src/top/AttractionBuilding.tsx` の `AttractionInfoBoard` |
| 建物名 | 同ファイルの `title` / `subtitle`（棟のバナー。ここは固有名） |
| スタートカード | 各ゲームの `i18n.ts` / Overlays の `subtitle` / `storyLine` / `tagline` |

---

## 1. 書く場所の役割

| 欄 | 役割 | 書いてよいこと | 書いてはいけないこと |
|----|------|----------------|----------------------|
| `title` | 棟の正式名称 | MEET SERGITO など固有名 | キャッチコピーを足さない |
| `subtitle`（棟） | 場所の呼び名 | The Workshop | 遊び方 |
| `storyTitle` | 看板の金見出し。一口の約束 | HE LOOKS / 職人が見る | 長い説明、操作、秒数 |
| `description` | 看板の本文。空気 | 扉、光、待つ人 | 「〜しよう」「制限時間は」 |
| スタートカード見出し | ライド名 | Shore Fishing | ルールタイトル化しない |
| スタートカード subtitle / storyLine / tagline | 入口の続き | 影。一振り。 | 手順の要約 |

操作説明・得点表は、スタートカードの **下段（controls / スコア表）** に置く。上段のプレゼンと混ぜない。

---

## 2. 文字量（入口看板）

看板パネルは約 **3.05 × 1.58**。本文 `maxWidth` は **2.7**。これを超えると折り返して見出しと重なる。

| 欄 | 行数 | EN（目安） | JA（目安） | 備考 |
|----|------|------------|------------|------|
| `storyTitle` | **1行のみ** | **16字以内** | **10字以内** | `whiteSpace: nowrap`。長いと切れる |
| `description` | **2行**（最大3） | **1行 20字以内** | **1行 11字以内** | `\n` で自分で改行する。長い英文を1行に詰めない |
| 棟 `title` | 1行 | 既存の正式名 | — | むやみに伸ばさない |
| 棟 `subtitle` | 1行 | 2〜4語 | — | The Workshop など |

スタートカードの subtitle / tagline も同じ密度。**一文で空気が分かること。** 操作は別行。

---

## 3. トーン：ディズニー入口 × 具体

問うこと:

> ディズニーなら、この入口に何と書くか？

書く:

- 約束（何が待っているか）
- **具体物**（群衆、ランウェイ、台座、魚影、棚の人形、動く的）
- 感覚（光、音、高さ、視線）
- 短い招待（扉は開いている）

書かない:

- 抽象詩だけ（「金は鳴る」「海が決める」「同じ目だ」— 何の話か分からない）
- 機能説明（「Meebitを見て短いコメントをくれるよ」）
- 操作マニュアル（「ジャンプとダッシュで」「45秒」「加点・減点」）
- 仕様（「全20ステージ・約1000m」「正方形PFP」）
- おすすめ口調（「楽しもう」「体験しよう」「〜しよう」）
- 売り込み（「いま売り出されてるよ」）※パーク看板。店内の値札は別

**Bad（抽象すぎ）**

> HE LOOKS / 職人が見る  
> 工房の扉は開く。 / Meebitを見せて。

> AIM TRUE / 狙い打て  
> 金は鳴る。 / 赤は噛む。

**Good（空気 + 場面）**

> MEET SERGITO / Sergitoが待つ  
> Wood shop by the sea. / Figures on shelves.  
> 海辺の木の工房。 / 棚に並ぶ人形たち。

> FIND ONE / ひとり探せ  
> Crowd in the gallery. / One face stands out.  
> 美術館の群衆。 / ひとりだけ違う。

機能は説明しなくても、入ったあとに分かる。看板は **入りたくなる一文** で足りる。ただし **何が見えるか** は一言入れる。

---

## 4. 言語

- 日本語は最初から日本語で書く。英語の直訳禁止
- 常体。ですます・「〜しよう」を看板本文に使わない
- 英語は短い口語。`amazing` / `experience` / `enjoy` 禁止寄り
- EN / JA は同じ約束を共有すればよく、語順は一致させない

---

## 5. チェック

看板を足す・直すとき:

1. `storyTitle` は1行に収まるか（EN 16 / JA 10）
2. `description` の各行は制限内か。プレビューで折り返していないか
3. 秒数・操作・UI名・ステージ数が上段に出ていないか
4. 広告に載せられそうなら、もっと短く具体的な物へ直す
5. スタートカード上段も同じトーンか。ルールは下段か
